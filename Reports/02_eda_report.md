# Exploratory Data Analysis Report

## Objective
Understand the dataset before business analysis.

## Analysis Performed
- Dataset Shape
- Data Types
- Missing Values
- Duplicate Records
- Statistical Summary
- Correlation Analysis
- Distribution Analysis
- Outlier Detection

## Visualizations
- Histograms
- Boxplots
- Heatmap
- Countplots
- Line Charts
- Bar Charts

## Findings
- Missing values were identified and handled.
- Duplicate records were removed.
- Date columns were converted into datetime format.
- Numerical features were analyzed for distribution.
