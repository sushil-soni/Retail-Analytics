# 🛒 Retail Analytics

An end-to-end Data Analytics project built using the **Olist Brazilian E-Commerce Dataset**. This project demonstrates the complete analytics workflow, from raw data processing to business insights using SQL and Python.

---

# 📌 Project Overview

The objective of this project is to analyze e-commerce sales data, identify business trends, and generate actionable insights that can help improve sales performance, customer satisfaction, and operational efficiency.

---

# 🎯 Objectives

- Clean and preprocess raw data
- Design a relational database in MySQL
- Perform SQL-based business analysis
- Conduct Exploratory Data Analysis (EDA)
- Create meaningful features for analysis
- Generate business insights using Python
- Visualize key business metrics
- Document the complete analytics workflow
