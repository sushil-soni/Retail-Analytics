# Project Workflow

This project follows a complete end-to-end Data Analytics workflow using Excel, MySQL, Python, and Dashboard Development.

---

## Phase 1 - Data Collection

- Download the Olist E-commerce Dataset.
- Store all raw CSV files inside the `data/raw/` folder.
- Verify the dataset structure.

---

## Phase 2 - Data Understanding (Excel)

- Open each CSV file in Microsoft Excel.
- Understand the tables and relationships.
- Identify important columns.
- Check for missing values and data types.
- Understand the business problem.

---

## Phase 3 - Database Design

- Design the relational database.
- Identify Primary Keys.
- Identify Foreign Keys.
- Create the relationship between tables.

---

## Phase 4 - SQL

- Create the database.
- Create all required tables.
- Import CSV files using `LOAD DATA INFILE`.
- Execute business queries.
- Validate imported data.

---

## Phase 5 - Python 

- Connect Python with MySQL.
- Load data into Pandas DataFrames.
- Perform data cleaning.
- Handle missing values.
- Merge tables for analysis.

---

## Phase 6 - Exploratory Data Analysis 

- Sales Analysis
- Customer Analysis
- Product Analysis
- Seller Analysis
- Payment Analysis
- Review Analysis

---

## Phase 7 - Dashboard Development 

- Build an interactive dashboard using Python.
- Add KPI Cards.
- Create interactive charts.
- Add filters.
- Display business insights.

---

## Phase 8 - Reports & GitHub 

- Generate project reports.
- Capture dashboard screenshots.
- Prepare GitHub repository.
- Write project documentation.
